Arquitetura do Projeto

Critérios técnicos aplicados para atender os requisitos de infraestrutura e conteinerização na nuvem.

Arquitetura Isolada

O sistema é dividido em Backend e Frontend. Configuração rigorosa de Virtual Private Cloud (VPC) garante que apenas a aplicação Web acesse o servidor da API.

Principal

Deploy com Docker

Tanto o back-end (porta 25000) quanto o front-end (porta 8080) foram empacotados em containers via Dockerfile, garantindo portabilidade e padronização.

Hospedagem EC2

Utilização de Máquinas Virtuais (VMs) na infraestrutura AWS EC2. Security Groups configurados para liberar tráfego externo apenas na porta 8080.
